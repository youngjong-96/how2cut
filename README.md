# How2Cut

알루미늄 원자재 길이와 절단해야 할 길이/수량을 입력하면 필요한 원자재 개수와 절단 배치를 계산하는 웹 도구입니다.

## 현재 버전

현재 버전은 브라우저에서 바로 사용할 수 있는 MVP입니다.

- 원자재 길이, 절단 손실값, 절단 길이/수량 입력
- 최적 또는 근사 절단 계획 계산
- 최적화 우선순위 선택
  - 균형 우선
  - 최소 잔재 우선
  - 최소 길이 변경 우선
  - 최소 원자재 변경 우선
- 작업자가 따라갈 수 있는 현장 작업 순서표
- 원자재별 절단 막대 시각화
- 반복 절단 패턴 요약
- 계산 결과 복사
- 입력값 공유 링크 복사
- 작업자용 인쇄 보고서 출력
- 모바일/데스크톱 반응형 UI
- Web Worker 기반 계산 처리

## 기술 스택

- Next.js App Router
- TypeScript
- React
- Tailwind CSS
- Zod
- Vitest
- Vercel 배포 기준 구성
